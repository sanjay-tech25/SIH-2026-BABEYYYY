# Error Mitigation

## Definition
**Error Mitigation** techniques suppress software/hardware error impact on NISQ expectation values without full quantum error correction overhead. Key methods include **Zero-Noise Extrapolation (ZNE)** and **Probabilistic Error Cancellation (PEC)**.
