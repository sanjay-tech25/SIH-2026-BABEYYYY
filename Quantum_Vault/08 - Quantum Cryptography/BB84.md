# BB84

## Problem
Alice wants to securely establish a secret random binary key string with Bob over an insecure channel, guaranteeing eavesdropping detection.

## Protocol Steps
1. **Prepare**: Alice generates random bits and chooses random bases for each bit:
   - Computational basis $Z$: $\{|0\rangle, |1\rangle\}$
   - Hadamard basis $X$: $\{|+\rangle, |-\rangle\}$
2. **Transmit**: Alice sends single photons in prepared states to Bob.
3. **Measure**: Bob chooses random bases ($Z$ or $X$) to measure each arriving photon.
4. **Sift**: Alice and Bob publicly compare measurement bases via classical channel, discarding bits where bases differed ($~50\%$ kept).
5. **Eavesdropping Check**: Compare sample subset of sifted bits. If Quantum Bit Error Rate (QBER) $> 11\%$, Eve was eavesdropping!

## Qiskit Implementation
```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

def bb84_channel_simulation(n_bits=8):
    alice_bits = np.random.randint(0, 2, n_bits)
    alice_bases = np.random.randint(0, 2, n_bits)  # 0=Z, 1=X
    bob_bases = np.random.randint(0, 2, n_bits)
    
    # Circuit simulation
    qc = QuantumCircuit(n_bits, n_bits)
    for i in range(n_bits):
        if alice_bits[i] == 1:
            qc.x(i)
        if alice_bases[i] == 1:
            qc.h(i)
        # Bob measures in his basis
        if bob_bases[i] == 1:
            qc.h(i)
        qc.measure(i, i)
        
    sim = AerSimulator()
    counts = sim.run(qc, shots=1).result().get_counts()
    bob_measured = [int(b) for b in list(counts.keys())[0][::-1]]
    
    # Sifting matching bases
    sifted_key = [alice_bits[i] for i in range(n_bits) if alice_bases[i] == bob_bases[i]]
    return sifted_key

print("BB84 Sifted Secret Key Sample:", bb84_channel_simulation(16))
```
