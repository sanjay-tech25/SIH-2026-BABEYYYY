# Phase Flip Code

## Definition
Encodes 1 logical qubit into 3 physical qubits in the Hadamard basis $\{|+\rangle, |-\rangle\}$ to protect against Pauli $Z$ phase errors:
$$|0_L\rangle = |+++\rangle, \quad |1_L\rangle = |---\rangle$$
