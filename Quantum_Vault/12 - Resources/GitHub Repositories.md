# GitHub Repositories

## Overview
Curated list of authoritative open-source repositories for quantum algorithms, SDK frameworks, and educational tutorials.

---

## Recommended Repositories

### 1. Qiskit SDK
- **URL**: https://github.com/Qiskit/qiskit
- **What It Teaches**: Core open-source codebase of Qiskit SDK, gate implementations, transpiler passes, and circuit optimization.
- **Notes Supported**: [[Qiskit]], [[Python]], [[Algorithm Implementations]]

### 2. Qiskit Community Tutorials
- **URL**: https://github.com/Qiskit/qiskit-tutorials
- **What It Teaches**: Jupyter notebook implementations of textbook quantum algorithms, NISQ chemistry simulations, and optimization.
- **Notes Supported**: [[Deutsch-Jozsa Algorithm]], [[Grover Algorithm]], [[Shor Algorithm]], [[VQE]], [[QAOA]]

### 3. PennyLane (Xanadu)
- **URL**: https://github.com/PennyLaneAI/pennylane
- **What It Teaches**: Differentiable quantum programming framework for Quantum Machine Learning and variational algorithms.
- **Notes Supported**: [[VQE]], [[QAOA]]

### 4. Cirq (Google Quantum AI)
- **URL**: https://github.com/quantumlib/Cirq
- **What It Teaches**: Python framework for writing, manipulating, and optimizing NISQ quantum circuits on Google Sycamore processors.
- **Notes Supported**: [[Quantum Gates]], [[Circuit Experiments]]
