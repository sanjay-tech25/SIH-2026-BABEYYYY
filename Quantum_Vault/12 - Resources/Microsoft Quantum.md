# Microsoft Quantum

## Overview
**Microsoft Quantum** provides quantum computing solutions through Azure Quantum, featuring Q#, the Quantum Development Kit (QDK), and topological qubit hardware research.

---

## Key Platforms & Documentation Resources

### 1. Azure Quantum
- **URL**: https://azure.microsoft.com/en-us/products/quantum
- **What It Teaches**: Cloud access to multi-provider quantum hardware (IonQ, Quantinuum, Rigetti) and resource estimators.
- **Notes Supported**: [[Qiskit]], [[Resource Estimation]], [[Algorithm Implementations]]

### 2. Quantum Katas
- **URL**: https://github.com/microsoft/QuantumKatas
- **What It Teaches**: Open-source, self-paced programming exercises covering quantum superposition, entanglement, phase estimation, and Grover search in Q#.
- **Notes Supported**: [[Superposition]], [[Entanglement]], [[Phase Kickback]], [[Quantum Phase Estimation]], [[Grover Algorithm]]

### 3. Microsoft QDK Documentation
- **URL**: https://learn.microsoft.com/en-us/azure/quantum/
- **What It Teaches**: Domain-specific quantum programming language (Q#) syntax, quantum algorithm libraries, and Hamiltonian simulation.
- **Notes Supported**: [[VQE]], [[Quantum Fourier Transform]], [[Shor Algorithm]]
